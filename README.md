# Mini Game Collection 

A collection of small, fast-paced mini-games inspired by games like **WarioWare** and **Dumb Ways to Die**.

The goal is simple: complete each challenge as quickly and accurately as possible.

## Mini-Games

* **Hammer** - Hit the nails before time runs out.
* **Paint** - Paint the required area of the wall.
* More mini-games coming soon...

##  Features

* Fast and simple mini-games
* Short gameplay sessions
* Simple controls
* Different challenges and mechanics
* Lightweight 2D gameplay

##  Built With

* **Godot**
* **GDScript**

This project is still being developed, and new mini-games and features may be added over time.
